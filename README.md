# Matcher Game

## Description
**Rules**. There're some cards, all "closed" at the beginning.
The players take turns opening cards. Each turn a player opens two cards and
everybody can see the values of the cards. Then the cards are turned over to be closed.
If the player opens cards with the same values he or she takes them and then takes the
turn again. The game ends when all the cards are taken by players. The winner is who
collects more cards than others.

We plan to implement the following features in the future.

- Playing against computer (bots)
- Playing via the internet (online version)
