    Matcher Game Project Notes


Description :
- There are some (say 20) cards;
- Each card has a number and a value:
    - number: a player opens the card by its number;
    - value: a letter like "a", "b", "c" etc.,
    when the card is open the value is shown;
- Moves :
    - a player must open two cards by typing two numbers,
    like "3 16"
    - then, these two card's values are shown, like "f a",
    the player needs to memorize the values;
    - so, if the values are the same, the player takes the cards
    and make the next move;
    - if the values are NOT the same, the next player moves;
- Goal: the winner is who collects more cards than others;
- Idea: the game is inspired by Pexeso game;


Game Session Example :
> player names : sam bob
> number of cards : 20
>
> sam : 2 7
> b f
>
> bob : 2 11
> b e
>
> sam : 6 14
> c b
>
> bob : 2 14
> b b - match
>
> bob : 7 12
> f j
>
> sam : ...


Player Input types :
- "abc54,.ert" :
    - not a two-positive-integer-numbers string [INVALID];
- "6 6" :
    - valid,
    - but contains two equal numbers;
- "65 123" :
    - valid,
    - different numbers,
    - but contains a number that does not belong to any card;
- "12 7" :
    - valid,
    - different numbers,
    - not too big numbers,
    - but contains a card that is already taken by a player
    (a non-active card);
- "11 17" :
    - two active cards [CORRECT];


Terms :

Settings Items :
- [Check Box] Show Intro Info
- [Check Box] Go to next player on incorrect input,
  "incorrect" indeed, not "invalid"
